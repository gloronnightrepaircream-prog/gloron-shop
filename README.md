# GLORON BEAUTY Ecommerce Website
This is a mobile-first static website starter using the supplied GLORON video/images and the product information provided in chat.

## Included
- Hero video
- Product gallery
- Ingredient section
- How-to-use section
- Product details
- Cart UI
- Review submission UI
- FAQ
- Shipping/payment information
- Contact section
- WhatsApp link
- Razorpay integration placeholder

## Before launch
1. Complete Razorpay verification/KYC and connect the live payment integration.
2. Connect a real review database/backend. The current demo stores reviews in the visitor's browser only; it is not a shared online database.
3. Add final Privacy Policy and Terms & Conditions.
4. Confirm the final INCI list. The supplied label lists “Booster — To be identified”, so this site does not invent its identity.
5. Resolve the price discrepancy: the supplied label image shows MRP ₹1,499, while the requested website selling price is ₹1,599. This should be resolved before launch.
6. Add Instagram/Facebook URLs when ready.
